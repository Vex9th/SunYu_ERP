# 采购操作授权联动修复

用户反馈：主账号勾选采购单新建、修改、确认、到货、付款和进项发票后，成员仅看到库存入口，库存也不能修改。

## 原因与修复

原目录仅声明同模块的查看依赖。项目入口要求 `projects.view`，采购选料要求 `procurement.lines.view`，供应商选项要求 `companies.view`，单价、付款及发票金额输入要求 `sensitive.procurement_prices`。旧工作组可以合法保存缺少这些前置条件的操作授权。

本次增加页面工作流依赖，勾选操作时递归联动必要的入口、选项和价格查看权限；可见项目为空时明确提示。旧工作组展示缺失项和“补齐所需权限”按钮，主账号核对勾选并点击“保存项目与权限”后才生效。目录读取、登录和升级不会自动扩大旧账号权限，不修改项目授权范围。

“管理项目库存”用于项目领用与冲销；新增物料、修改资料和调整库存数量需要“管理共享库存”。采购授权不会自动开放共享库存修改。

撤销查看权限只撤下依赖本次取消项的操作，不清空旧组其他尚未补齐的权限。保存成功提示在重新读取工作组后保留，再次编辑授权时清除。

## 旧版临时设置步骤

1. 主账号进入“账号与权限 → 工作组与授权”，选择成员所属工作组。
2. 在“可见项目”中选中对应项目。
3. 保留原采购操作与查看权限，另勾选“查看项目资料”“查看公司基础资料”“查看采购清单”“查看采购价格”。
4. 点击“保存项目与权限”，成员刷新权限或重新登录。
5. 进入“项目中心 → 对应项目 → 采购管理”。如确需修改共享库存，再单独开放“查看共享库存”和“管理共享库存”。
